## Test Conventions (based on existing tests)

- Use `vi.mock()` at module level to mock CMS hooks and external deps
- Use `vi.clearAllMocks()` in `beforeEach`
- Wrap pages in `<MemoryRouter>` when they use routing
- Use `screen.getByText()` / `screen.queryByText()` for assertions
- Use `@testing-library/user-event` for interactive tests
- Test conditional rendering (loading, error, empty, loaded)
- Follow the `__tests__/` directory pattern colocated with source
