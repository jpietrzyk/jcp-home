- **Hamburger icon:** Standard Menu icon (three-line hamburger) from lucide-react

### 4. Add fixed-position logo to topbar that follows sidebar

**File:** `MainLayout.tsx` — inside the header element

Add a fixed-position logo that:
- Is `position: fixed`, `top` aligned with the header
- `left` is set to `var(--sidebar-width-icon)` when collapsed, or dynamically follows the sidebar edge
- Uses the square variant when sidebar is collapsed, full variant when expanded

Implementation approach — add inside the `<SidebarInset>` area, rendered as part of the header:

```tsx
<header className="sticky top-0 z-10 flex h-10 shrink-0 items-center gap-2 bg-transparent px-3">
  <Link
    to="/"
    aria-label="JCP Home"
    className="fixed top-1.5 z-20 flex items-center justify-center rounded-md transition-[left] duration-200 ease-linear hover:bg-stone-100 dark:hover:bg-stone-800/60"
    style={{ left: 'calc(var(--sidebar-width-icon) + 0.5rem)' }}
  >
    <JcpLogo
      variant="tertiary"
      className="h-6 w-auto group-data-[collapsible=icon]:hidden"
    />
    <JcpLogo
      variant="square"
      className="hidden group-data-[collapsible=icon]:block h-7 w-7"
    />
  </Link>
  <div className="flex-1" />
</header>
```

**Note:** The `group-data-[collapsible=icon]` selectors work because the header is inside `SidebarProvider`, and the sidebar wrapper `div` has `group/sidebar-wrapper` class. To make this work, the logo needs to be aware of sidebar state. Options:

**Option A (recommended):** Use `useSidebar()` hook to read `state` directly:
```tsx
function TopBarLogo() {
  const { state } = useSidebar();
  return (
    <Link
      to="/"
      aria-label="JCP Home"
      className="fixed top-1.5 z-20 flex items-center justify-center rounded-md transition-[left] duration-200 ease-linear hover:bg-stone-100 dark:hover:bg-stone-800/60"
      style={{ left: state === 'collapsed' ? 'calc(var(--sidebar-width-icon) + 0.75rem)' : 'calc(var(--sidebar-width) + 0.75rem)' }}
    >
      {state === 'expanded' ? (
        <JcpLogo variant="tertiary" className="h-6 w-auto" />
      ) : (
        <JcpLogo variant="square" className="h-7 w-7" />
      )}
    </Link>
  );
}
```

This gives precise control over positioning based on sidebar state.
