# Plan: Align ProjectsPage with Music/Blog Page Style

## Problem

`ProjectsPage` is architecturally inconsistent with `MusicPage` and `BlogListPage`. It lacks:
- `PageTransition` wrapper (framer-motion page animation)
- `PageHero` component (card-based hero section with title/subtitle)
- `CmsPageContent` for rich text body rendering
- `SectionHeading` for the "Projects" section heading with icon
- Wider spacing (`space-y-10` vs `space-y-6`)
- Animated eyebrow wrapped in `AnimatedSection`

## Changes Required

### 1. Rewrite `ProjectsPage.tsx`

**File:** `dev/web/src/pages/ProjectsPage.tsx`

Refactor to match the `BlogListPage` pattern (closest structural match — list of cards with a section heading):
