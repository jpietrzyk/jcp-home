# Replace Logo with logo-1.svg and Add Favicon

## Context
Currently the logo is an inline SVG React component (`JcpLogo.tsx`) that renders text/paths directly. The new logo (`src/assets/logo-1.svg`) is a static SVG file with hardcoded colors (no CSS variables). It needs to replace the inline component in all usage sites and also serve as the favicon.

## Files Affected

| File | Change |
|------|--------|
| `dev/web/src/components/JcpLogo.tsx` | Replace inline SVG with `<img>` importing `logo-1.svg` |
| `dev/web/index.html` | Add `<link rel="icon">` favicon tag pointing to logo-1.svg |
| `dev/web/src/components/__tests__/JcpLogo.test.tsx` | Update tests to match new `<img>`-based component |

## Steps

### 1. Rewrite `JcpLogo.tsx` to use the static SVG asset
- Import `logo-1.svg` as a URL (Vite handles `?url` or default asset import)
- Render an `<img>` tag instead of inline SVG markup
- Keep the same props interface (`React.ImgHTMLAttributes<HTMLImageElement>`) — note: change from `SVGProps` to `ImgHTMLAttributes` since it's now an `<img>`
- Preserve `aria-hidden` / accessibility logic

### 2. Add favicon to `index.html`
- Add `<link rel="icon" type="image/svg+xml" href="/src/assets/logo-1.svg" />` in `<head>`
- Vite will process this automatically during dev and build

### 3. Update tests in `JcpLogo.test.tsx`
- The component now renders an `<img>` instead of `<svg>`, so selectors and assertions need updating:
  - `container.querySelector("svg")` → `container.querySelector("img")`
  - SVG-specific assertions (className.baseVal, fill classes) → img attribute assertions (src, alt, aria-hidden)
  - Accessibility tests remain conceptually the same but check `<img>` attributes
