# Plan: Fix Sidebar Mobile Visibility & Collapsible Consistency

## Problem

The sidebar is hidden on mobile with no visible indicator to open it. Additionally, the desktop sidebar should support toggling between expanded and collapsed (icon-only) states with a clear UI affordance.

## Root Cause

The shadcn `Sidebar` component already has full mobile (Sheet/overlay) and desktop icon-collapse support built in. The issue is:

1. The `SidebarHeader` layout uses custom flex centering with a `w-3/4` logo that doesn't adapt to the collapsed icon state (2.5rem wide).
2. `SidebarMenuButton` items don't specify `tooltip` props — no tooltips appear when collapsed, making the collapsed state confusing.
3. `SidebarRail` is not included — no edge-click affordance for toggling.

## Changes

### 1. `src/components/JcpLogo.tsx` — Add `square` variant

- Import `jcp-logo-square.svg` from assets.
- Add `"square"` variant to the `variantSrc` map.
- This provides the compact square logo for the collapsed sidebar state.

### 2. `src/layouts/MainLayout.tsx` — Fix sidebar behavior

Changes:

1. **Import `SidebarRail`** from `@/components/ui/sidebar`.
2. **Fix `SidebarHeader` logo** — Show `jcp-logo-square.svg` when sidebar is collapsed (icon mode):
   - Full logo: visible by default, hidden with `group-data-[collapsible=icon]:hidden`.
   - Square logo: hidden by default, shown with `hidden group-data-[collapsible=icon]:flex`.
   - Adjust padding for collapsed state: `group-data-[collapsible=icon]:pt-4 group-data-[collapsible=icon]:px-2`.
3. **Add `tooltip` prop** to all `SidebarMenuButton` instances (nav links + social links) so collapsed-state tooltips work.
4. **Add `<SidebarRail />`** before closing `</Sidebar>` — provides a thin clickable edge strip for toggling (desktop only via `sm:flex`).

### No changes to `src/components/ui/sidebar.tsx`

The shadcn sidebar primitive already handles:
- **Mobile (<768px):** Renders as a `Sheet` (overlay drawer). `SidebarTrigger` opens it.
- **Desktop:** `collapsible="icon"` (default) shrinks to 2.5rem showing icons + tooltips. `Ctrl+B` shortcut toggles.
- State persisted in `sidebar_state` cookie (7-day expiry).

## Files Modified

| File | Change |
|---|---|
| `src/components/JcpLogo.tsx` | Add `square` variant using `jcp-logo-square.svg` |

## Testing

- **Mobile (<768px):** Tap `SidebarTrigger` → sidebar opens as overlay sheet with full logo + all links.
- **Desktop expanded:** Full sidebar with `jcp-logo.svg`, all labels visible.
- **Desktop collapsed:** Sidebar shrinks to icon column (2.5rem), shows `jcp-logo-square.svg`, icon-only buttons with tooltips on hover.
- **Footer:** Unaffected (inside `SidebarInset`).
