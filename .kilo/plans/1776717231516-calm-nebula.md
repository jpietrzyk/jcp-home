# Plan: Add Contact Page

## Overview

Add a `/contact` route with a Contact page featuring:
- Contact info section (email, phone, location, LinkedIn, GitHub) sourced from existing `profile.ts`
- A contact form with a single textarea and send button (Netlify Forms)
- Humanity check (honeypot field) before submission
- Help text: "...what's on yr mind?"
- Navigation entry in sidebar and footer

## Files to Modify

### 1. Create `dev/web/src/components/ui/textarea.tsx`
- Add shadcn/ui-style `Textarea` component (matching existing component conventions)
- Standard `<textarea>` with Tailwind styling, `cn()` utility, `React.forwardRef`

### 2. Create `dev/web/src/pages/ContactPage.tsx`
- Follow `MusicPage.tsx` conventions: `PageTransition` > `AnimatedSection` > `PageHero` + `CmsPageContent`
- CMS integration via `useCmsPage("contact", { fallback: {...} })` with sensible defaults
- **Contact info section** — card showing email, phone, location, LinkedIn, GitHub using `profile` data and lucide icons (`Mail`, `Phone`, `MapPin`, plus inline `LinkedInIcon`/`GitHubIcon` or just links)
- **Contact form section** — `<form>` with:
  - `name="contact"` attribute + `data-netlify="true"` for Netlify Forms
  - `<input type="hidden" name="form-name" value="contact" />` (required by Netlify)
  - Honeypot field: `<div className="hidden"><input name="bot-field" /></div>` for humanity check (invisible to users, bots fill it → submission rejected)
  - `<Textarea>` with placeholder "...what's on yr mind?" and `name="message"`
  - `<Button type="submit">Send</Button>`
  - Basic React state for form submission feedback (success/error messages)
- Use `fetch("/", { method: "POST", body: formData })` for Netlify form submission (standard Netlify SPA approach)

### 3. Modify `dev/web/src/layouts/MainLayout.tsx`
- Add `{ to: "/contact", label: "Contact", icon: Mail }` to the `links` array (after Music)
- `Mail` icon is already imported
- Footer automatically picks up the new link (it iterates `links`)

### 4. Modify `dev/web/src/router.tsx`
- Add `{ path: "contact", element: <ContactPage /> }` to `children` array
- Import `ContactPage` from `./pages/ContactPage`

### 5. Create `dev/web/src/pages/__tests__/ContactPage.test.tsx`
- Follow `MusicPage.test.tsx` patterns
- Mock `useCmsPage`
- Test: renders page title, subtitle, contact info, form elements, submit button
- Test: form has correct Netlify attributes (`data-netlify`, `form-name` hidden input)
- Test: honeypot field exists and is hidden
- Test: textarea has correct placeholder
- Test: submission success/error states

## Implementation Order

1. Create `Textarea` UI component
2. Create `ContactPage` component
3. Add route to `router.tsx`
4. Add link to `MainLayout.tsx`
5. Add tests for `ContactPage`

## Notes

- **No new dependencies needed** — honeypot approach uses plain HTML, no CAPTCHA library required
- **Netlify Forms**: The `netlify.toml` already deploys from `dev/web` to Netlify. Forms are auto-detected from the HTML. SPA submission uses `fetch POST` to `/` with encoded form data.
- **CMS fallback**: The page works without a Sanity CMS "contact" document — fallback provides title/subtitle/eyebrow. A CMS document can be added later in Sanity Studio for richer content.
