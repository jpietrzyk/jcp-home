# Plan: Improve Home Page Intro Spacing & List Colors

## Problem

The home page hero section appears as one undifferentiated block of text due to:
1. Only 16px (`gap-4`) between the title block and content area
2. Only 16px (`space-y-4`) between CMS rich text, contact links, and CTA buttons
3. `@tailwindcss/typography` is **not installed** -- the `prose` class on CMS rich text does nothing, so paragraph spacing, heading margins, and list styling rely on browser defaults
4. List items (`<li>`) inherit `text-stone-600` (gray/brown) color, making bullets and text look faded
5. No explicit `line-height` on the content wrapper -- defaults may be too tight

## Changes

### 1. Install `@tailwindcss/typography` plugin

**Why:** The `prose` class is already used in `CmsRichText.tsx` and passed via `richTextClassName` in `HomeHeroSection.tsx`, but the plugin is not installed so it has zero effect. Installing it provides proper paragraph spacing, heading margins, list styling, and line-height out of the box.

**Files:**
- `dev/web/package.json` -- add `@tailwindcss/typography` dependency
- `dev/web/vite.config.ts` -- import and register the plugin via `tailwindcss.vite({ ... })` or update CSS to import it

**Note:** Tailwind v4 uses `@plugin "@tailwindcss/typography"` in CSS instead of a JS config file. Verify the correct integration method.

### 2. Fix list item color (remove gray)

**File:** `dev/web/src/components/CmsRichText.tsx`

- Add explicit text color classes to list elements so they inherit proper body text color instead of the muted `stone-600` from the parent
- Update `portableTextComponents`:
  - `<ul>` / `<ol>`: add `text-stone-800 dark:text-stone-200` to override the muted gray
  - Alternatively, remove `text-stone-600` from the rich text container class and use a less muted color

**Also update:** `dev/web/src/components/home/HomeHeroSection.tsx` line 65
- Change `richTextClassName` from `"prose prose-stone text-stone-600 dark:prose-invert"` to something like `"prose prose-stone dark:prose-invert"` (let `prose` handle color, or use a darker text color like `text-stone-800 dark:text-stone-200`)

### 3. Increase spacing inside PageHero

**File:** `dev/web/src/components/PageHero.tsx`

| Element | Current | Proposed | Reason |
|---|---|---|---|
| Title-to-content gap | `gap-4` (16px) | `gap-8` (32px) | Clear separation between header and body |
| Content children spacing | `space-y-4` (16px) | `space-y-8` (32px) | Visible gap between rich text, contacts, and buttons |
| Card padding | `p-6 md:p-8` | `p-8 md:p-10` | More breathing room inside the card |

### 4. Add line-height to content wrapper

**File:** `dev/web/src/components/PageHero.tsx`

- Add `leading-relaxed` (1.625) or `leading-loose` (2.0) to the content wrapper `<div className="text-lg md:text-xl space-y-4">` to improve readability of paragraphs

### 5. Add spacing to CMS rich text paragraphs (if typography plugin not sufficient)

**File:** `dev/web/src/components/CmsRichText.tsx`

- If after installing `@tailwindcss/typography` the paragraph spacing is still insufficient, add explicit margin classes to `<p>` and heading blocks in `portableTextComponents`:
  - `<p>`: add `className="my-4"` (16px top+bottom margin)
  - `<h2>`: add `className="mt-8 mb-4 text-2xl font-bold"`
  - `<h3>`: add `className="mt-6 mb-3 text-xl font-semibold"`

### 6. Add margin between contact links and CTA buttons

**File:** `dev/web/src/components/home/HomeHeroSection.tsx`

- Wrap contact links and CTA buttons in containers with explicit top margins:
  - Contact links div: add `mt-2` (already handled by `space-y-8` from parent, but may need fine-tuning)
  - CTA buttons div: consider adding `pt-2` for extra visual separation
