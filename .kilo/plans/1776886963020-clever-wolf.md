# Experience Timeline Refactor

## Goal

Make the Work Experience section on the About page look like a timeline with:
1. Bigger gaps between experience cards
2. Start/end dates displayed **above** and **below** each card (outside the card), instead of inside the card header

## Files to Modify

### 1. `dev/web/src/pages/AboutPage.tsx` — Increase gap between experience cards

- Change the experience list container from `<div className="space-y-6">` to `<div className="space-y-8">` (or `space-y-10` to match the top-level section spacing) on line 87

### 2. `dev/web/src/components/resume/ResumeJobExperience.tsx` — Extract dates into timeline markers

**Current layout:**
```
┌─────────────────────────────────────────┐
│ Position Title            Jun '24 — Present │
│ 🏢 Company  📍 Location   [type badge] │
│ ✅ Achievement 1                         │
│ ✅ Achievement 2                         │
└─────────────────────────────────────────┘
```

**New layout:**
```
      Jun '24
┌─────────────────────────────────────────┐
│ Position Title                           │
│ 🏢 Company  📍 Location   [type badge] │
│ ✅ Achievement 1                         │
│ ✅ Achievement 2                         │
└─────────────────────────────────────────┘
      Present
```

Changes:
1. **Remove** the date `<span>` from inside the card header (lines 49-52)
2. **Remove** the `Calendar` import (no longer needed inside the card)
3. **Remove** the `formatDateRange` helper (no longer needed)
4. **Add** a `startDate` display **above** the card — left-aligned `<p>` with styling `text-sm text-stone-500 dark:text-stone-400 mb-2`
5. **Add** an `endDate` display **below** the card — similar styling with `mt-2`
6. **Simplify** the header `<div>` from `flex flex-col sm:flex-row sm:items-start sm:justify-between` to just contain the `<h3>` (no date sibling)

The date text should be styled as subtle labels (e.g., `text-sm font-medium text-stone-500 dark:text-stone-400`) without the calendar icon — just the plain date text, positioned above and below the card to create the timeline feel.

If `isCurrent` is true and no `endDate` exists, display "Present" below the card.
